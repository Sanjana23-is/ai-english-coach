# AI Services

This directory will house the configurations, prompts, orchestration logic, and local AI model integration helpers.

## Planned Local AI Stack

- **Ollama**: Local runtime for conversational and analytical LLMs.
- **Whisper**: Local speech-to-text (STT) processing.
- **Piper**: Fast, local neural text-to-speech (TTS) synthesis.

> **Note:** Active AI services and integrations will be implemented during subsequent development phases. No paid third-party AI APIs are used.
